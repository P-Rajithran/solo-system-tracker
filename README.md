# Solo System

**Solo System** is a dark fantasy sci-fi gamified fitness & daily system tracker web application.

## Features
- **Hunter Master Profile & Stats**: Track Level, EXP, HP, STR, VIT, MEN, DIS, BMR & TDEE.
- **Daily Quests & Routine Tracking**: Physical workouts, meditation, micro-quests, and macro tracking.
- **Iron Sovereign Class Mechanics**: Ascend ranks from E-Rank Novice to S-Rank Iron Sovereign.
- **AI Nutrition Coach & Food Analyzer**: Integrated Gemini AI personal trainer & meal analyzer.
- **Instant Dungeons & Boss Raids**: Defeat gate bosses (including the Iron Colossus raid).
- **DiceBear Avatar Generator**: Dynamic sci-fi system bot avatars with custom seed generation and file uploads.
- **System Audio Effects**: Interactive SFX for level-ups, quest completions, and user interaction.

## Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS, React Router v7.
- **Backend**: Node.js, Express, MongoDB Mongoose, Google Gemini AI API.

## Running Locally

### Backend Server
```bash
cd backend
npm install
npm run dev
```

### Frontend Server
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
